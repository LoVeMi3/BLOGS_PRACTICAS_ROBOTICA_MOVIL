Paso 2: Decidir la rejilla

Define constantes al principio del archivo y usa numpy:

python
import numpy as np

RES = 0.1            # metros por celda
SIZE_M = 40.0        # tamaño del almacén (ajústalo)
N = int(SIZE_M / RES)
ORIGIN = N // 2      # el (0,0) del mundo cae en el centro de la matriz
grid = np.zeros((N, N))   # 0 = log-odds de p=0.5

Reutilizas: nada de tu código, pero grid = np.zeros(...) encaja con que el valor inicial sea 0 (por eso el prior 0.5 es cómodo).

Paso 4: Mundo → celda

No puedes usar WebGUI.worldToGrid, porque esa función es del mapa que te da el otro ejercicio, no de tu rejilla. Escribe la tuya:

python
def world_to_cell(x, y):
    col = int(x / RES) + ORIGIN
    row = int(y / RES) + ORIGIN
    return row, col

Añade una comprobación de límites (0 <= row < N y 0 <= col < N) antes de escribir en grid. Pruébala con (0,0), que debe dar (ORIGIN, ORIGIN), y con (1,0).

Paso 5: Actualizar con cada rayo

Aquí reutilizas más cosas:

rd(laser, i): ya te da la distancia saturada a 5 m. Si r < 5.0 hay obstáculo; si r >= 5.0 no hay hit.
El bucle for i in range(180) de repulsion, pero sin el continue de d > d_influence, porque para mapear sí quieres los rayos lejanos.
La convención de ángulos: en repulsion usas ox = d*sin(ang), oy = -d*cos(ang), es decir, índice 90 = frente, 0 = derecha, 180 = izquierda. Eso equivale a:
python
ang_world = pose.yaw + math.radians(i) - math.pi/2

Esqueleto:

python
def update_map(pose, laser):
    for i in range(180):
        r = rd(laser, i)
        ang = pose.yaw + math.radians(i) - math.pi/2
        # 1) recorre d = 0, RES, 2*RES ... mientras d < r
        #    x = pose.x + d*cos(ang); y = pose.y + d*sin(ang)
        #    celda -> grid[row, col] += L_BLANK
        # 2) si r < 5.0: celda en (r) -> grid[row, col] += L_TAKEN

Para el paso del recorrido usa RES o RES/2, para no saltarte celdas.
